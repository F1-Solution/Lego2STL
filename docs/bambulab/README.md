# Bambu Lab reference material

Reference for how Bambu Lab printers and Bambu Studio work, kept beside the code so a change to
the printing notes, the process preset or the plates can be checked against the source.

- **Bambu Lab wiki (Italian):** <https://wiki.bambulab.com/it/home> - Bambu Studio's menus,
  settings and workflows, and per-printer guides.
